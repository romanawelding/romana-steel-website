# Romana Steel & Welding L.L.C. — Website

A mobile-responsive static website prepared for free hosting on Cloudflare Pages and a future custom domain (`rsw.ae`).

## Files
- `index.html` — page content, SEO metadata and contact form
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation and email enquiry form

## Publish free with Cloudflare Pages
1. Create/sign in to a Cloudflare account.
2. Create a GitHub repository and upload these three files to its root.
3. In Cloudflare Dashboard, open **Workers & Pages → Create → Pages → Connect to Git**.
4. Select the repository. Choose **None** for framework preset, leave build command blank, and set build output directory to `/`.
5. Deploy. Cloudflare will provide a free `*.pages.dev` address.
6. Later, add `rsw.ae` in the Pages project under **Custom domains** and follow Cloudflare's DNS instructions. Register the domain separately in your own account first.

## Before going live
- Replace the illustrative stock photos in the hero, services and work gallery with approved Romana Steel project photos. The gallery is clearly labelled as illustrative until replaced.
- Confirm the company email address and add a business phone / WhatsApp number if desired.
- Add any verified trade licence details, certifications, project references and social links you want public.
- The enquiry form opens the visitor's email app; it does not store submissions on the website.

## Domain note
The website can be hosted free without buying a domain first. It will use a Cloudflare `pages.dev` address until you purchase and connect `rsw.ae`.
